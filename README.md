# yeshwanthgovindarajan.github.io

Personal portfolio site, based on the [dark-minimal](https://github.com/Gothsec/dark-minimal) Astro template.

**Live:** https://yeshwanthgovindarajan.github.io

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:4321

## Customize

Edit these files with your details:

- `src/layouts/Layout.astro` — page title, meta, OG tags
- `src/components/home.astro` — name and social links
- `src/components/projects.astro` — your projects
- `src/components/footer.astro` — footer, Spotify, copyright
- `src/components/contact.astro` — Formspree contact form endpoint

## Deploy

Pushes to `main` build and deploy via GitHub Actions (Pages).

In the repo settings, set **Pages → Source** to **GitHub Actions**.
